# Identificación Patrimonial por Código QR - Hospital I Félix Torrealva Gutiérrez

Este repositorio contiene la solución completa para la implementación de tarjetas físicas estáticas e identificación digital dinámica en tiempo real leída desde la base de datos SIPC.

## Estructura
- `/docs`: Documentación técnica y guía de usuario.
- `/public`: Código estático expuesto en la web (HTML, CSS, JS).
- `/scripts`: Automatización para generación masiva de archivos de impresión QR.
